# 🎮 Game Showcase & Personal Vault

Una aplicación web moderna, rápida y minimalista diseñada para registrar, calificar y analizar videojuegos jugados, en proceso y platinados. Funciona completamente del lado del cliente, sin servidores externos obligatorios y con almacenamiento local en el navegador.

## ✨ Características Principales

- **🔥 Modo Now Playing:** Sección destacada para tu partida activa actual.
- **🏆 Clasificación por Estados:** Jugando, Historia Completada, + Extras, Platinado (100%) y En Pausa.
- **🔍 Búsqueda de Carátulas Resiliente:** Búsqueda rápida integrada que no se bloquea por políticas de CORS en navegadores locales.
- **🎨 Generador Procedural Canvas:** Si juegas sin conexión o un juego no tiene carátula web disponible, el sistema dibuja automáticamente una portada tipográfica de alta definición.
- **📊 Panel de Estadísticas & Analytics:** Visualiza tu tasa de finalización, distribución de plataformas y horas promedio dedicadas.
- **📸 Exportador de Póster Top 5:** Genera al instante una imagen en formato PNG con tus mejores 5 juegos lista para compartir.
- **💾 Copias de Seguridad:** Exporta e importa toda tu biblioteca en formato JSON con un solo clic.
- **📱 Preparado para Móvil (PWA):** Añádelo a la pantalla de inicio de tu teléfono para usarlo a pantalla completa como una app nativa.

## 🛠️ Tecnologías Utilizadas

- **HTML5 & CSS3** (Vanilla)
- **Tailwind CSS** (Vía CDN)
- **FontAwesome Icons**
- **HTML5 Canvas API** (Generación procedural de carátulas y exportación de imágenes)
- **LocalStorage API** (Persistencia local)
